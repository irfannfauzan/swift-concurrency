# Swift Concurrency

Swift Concurrency to learn the difference between Grand Central Dispatch (GCD), OperationQueue, and async/await.
All three tabs show the same image gallery, one built with OperationQueue, one with GCD, and one with async/await.

## Tech stack

* Swift + UIKit
* Grand Central Dispatch (GCD)
* OperationQueue
* async/await
* NSCache
* UITableView with custom cells
